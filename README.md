# Explore RJ 🌊

Projeto educacional de desenvolvimento web com tema de turismo no Rio de Janeiro.

## Páginas
- `index.html`: página inicial com apresentação e destaques.
- `galeria.html`: galeria visual de paisagens.
- `contato.html`: formulário demonstrativo de contato.
- `style.css`: estilos, cores, cartões, animações e layout responsivo.
- `script.js`: menu para dispositivos móveis, ano automático e resposta demonstrativa do formulário.

## Como executar
Baixe os arquivos e abra `index.html` no navegador. As imagens e a fonte tipográfica dependem de conexão com a internet.

## Tecnologias
HTML5, CSS3 e JavaScript.
